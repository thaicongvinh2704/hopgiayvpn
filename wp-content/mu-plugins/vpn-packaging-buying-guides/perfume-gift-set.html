Design the gift set tray around every bottle

This rigid perfume gift box opens on a hinged lid to show a fitted tray. Draw the set before fixing the exterior dimensions. A discovery set with matching mini bottles needs a different layout from a bundle with a full-size bottle and smaller fragrance samples.

Map the cavities
Record the bottle outline, cap, filled weight and label direction for every position. Indicate whether each bottle will sit upright or lie flat and how the buyer should lift it out.
Compare tray materials using the same layout
Review paperboard or EVA options against the bottle shape and opening experience. Test finger clearance and glass separation with the actual bottles before approving the material and cavity layout.
Confirm the reveal
Specify the inner-lid logo position and space for a card if the set includes one. Close the lid over the full set and check for contact with caps and pressure on labels or decorative details.

Approve one filled sample for each set layout

Open the full set and confirm the bottle labels face the intended direction. Lift out each bottle and check that its neighbors stay in position. Close the lid and review the tray again after normal handling. For a repeat order, identify the approved tray layout alongside the bottle and artwork versions.
