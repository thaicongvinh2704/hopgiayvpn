Plan separate compartments for each jar or bottle

This compartmented gift box suits bird's nest sets that need several sealed jars or bottled drinks visible together. Map the layout from the actual set, including any product card, before committing to the exterior dimensions or print artwork.

Same-size jars
Measure the widest point and full height of a filled jar. Check the space between cavities and around the perimeter so each jar can be removed without disturbing its neighbors.
Mixed jars and bottles
Send a separate drawing or measurements for every container type. Mark each position on a simple layout and note which labels should face the customer when the box opens.
Insert and card
Compare paperboard and EVA if both are practical for the set. Check finger clearance, cap clearance under the closed lid and the space occupied by the card.

Check the complete set before approving the sample

Load every compartment, close the box and move it through the expected handling positions. Inspect for container contact, divider movement and pressure marks near the lid. Review the brand color and any logo finish on the approved material. For multiple versions, record which insert layout belongs to each set so reorders use the right arrangement.
