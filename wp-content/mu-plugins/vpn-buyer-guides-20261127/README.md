# Buyer guides release

After deployment on hopgiayvpn.com, open the Dashboard as an administrator and click **Xác nhận 3 bài blog đúng bản local**. The package was exported from the approved WordPress previews. Each article includes its exact body, excerpt, SEO fields, featured image and three inline images. The installer replaces the local site and media URLs with their hosting equivalents. It verifies the approved image files and sizes and checks that publishing preserved the staged body.

The update inserts one contextual link into each existing guide about shipping-box sizing, bakery packaging materials and greaseproof bakery bags. Earlier drafts in the Trash stay there. A matching active draft can be updated, and edited or unrelated posts are flagged for review. Repeating a completed confirmation returns the saved URLs.

The three linked products must be published before the confirmation so the articles retain the same links as the approved previews.
